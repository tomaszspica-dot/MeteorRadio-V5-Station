# Acknowledgements

The radio acquisition and meteor-detection foundation of this station is based on the upstream project:

- **MeteorRadio** by `rabssm`
- <https://github.com/rabssm/MeteorRadio>

The V5 station overlay adds local web interfaces, scoring/retention workflows, monitoring, deployment units and station-specific operational logic.

GRAVES at 143.050 MHz is used as the distant illumination source for meteor-scatter reception. This repository is an independent receiving-station project and is not affiliated with the GRAVES operator.
