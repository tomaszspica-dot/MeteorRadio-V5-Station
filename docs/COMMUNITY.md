# MeteorRadio V5 community

GitHub Discussions is the preferred place for community conversation around MeteorRadio V5.

## Where to post

- **General** — broad project conversation, operating experience, GRAVES meteor scatter, and project direction.
- **Q&A** — focused questions where an accepted answer can help future users.
- **Ideas** — proposed improvements, experiments, and feature concepts.
- **Show and tell** — station builds, detections, waterfalls, hardware, antennas, dashboards, and experiments.
- **Issues** — reproducible bugs or concrete work that should be tracked.
- **Pull requests** — proposed code or documentation changes.

## Recommended future custom categories

If the community grows, the default **Show and tell** category can be complemented by:

- **Show your station**
- **Detections**
- **Hardware**

GitHub currently requires discussion categories to be managed by a repository administrator from the Discussions category settings UI.

## Posting safely

Before posting terminal output, screenshots, or configuration files, remove:

- passwords and access tokens,
- private keys,
- exact private location data,
- private hostnames and IP addresses if they are not intended to be public.

For screenshots, crop unrelated browser tabs and personal account information.

## Tone

Keep discussions technical, constructive, and reproducible where possible. Share enough context that another user can understand the hardware, software, and observation conditions involved.
