# Publication checklist

Complete this before switching the GitHub repository to Public.

- [ ] `IMPORT_FROM_INSTALLER.command` completed successfully
- [ ] `VALIDATE_BEFORE_GITHUB.command` reports PASS
- [ ] no `.radar_config` with real coordinates
- [ ] no passwords, keys or tokens
- [ ] no raw SMP/audio archive
- [ ] no runtime likes/score/retention state
- [ ] no private hostnames/usernames in public docs or screenshots
- [ ] screenshots cropped and sanitized
- [ ] exact station location intentionally chosen as public or omitted
- [ ] upstream attribution present
- [ ] upstream GPLv3 status and issue #14 clarification reviewed
- [ ] if modified upstream core is included, GPLv3 license/copyright notices, modification notes and corresponding source are complete; otherwise it remains in ignored `private_reference/`
- [ ] repository description/topics set
- [ ] README renders correctly on GitHub
- [ ] release notes reviewed
- [ ] repository initially tested as Private

Only after all relevant boxes are complete should the repository be made Public.
