# License decision for this repository

No `LICENSE` file is intentionally included yet.

Reason: the public tree contains original station-layer material, but the overall project is tightly connected to an upstream project whose repository does not currently expose an explicit license. Selecting a license for this repository should not imply permission to relicense upstream-derived source.

A practical path is:

1. publish the overlay repository privately first;
2. ask upstream for license clarification;
3. decide the license for your original overlay code;
4. add a `LICENSE` file only after the boundary between original and upstream-derived material is clear.

Until a license is selected, others should not assume broad reuse rights for this repository.
