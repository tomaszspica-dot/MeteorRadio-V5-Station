# Start here

This folder is the documentation hub for publishing the reference MeteorRadio V5 station on GitHub.

Recommended order:

1. Read `../UPSTREAM_LICENSE_NOTICE.md`.
2. Run `../IMPORT_FROM_INSTALLER.command` on the Mac containing the final installer ZIP.
3. Read `ARCHITECTURE.md`, `SERVICE_MAP.md` and `DATA_FLOW_AND_RETENTION.md`.
4. Add sanitized screenshots following `SCREENSHOTS_TO_ADD.md`.
5. Run `../VALIDATE_BEFORE_GITHUB.command`.
6. Complete `PUBLICATION_CHECKLIST.md`.
7. Initialize Git with `../INIT_GIT_REPO.command` or do it manually.
8. Create the GitHub repository as **Private** first.
9. Resolve the upstream-license question before publishing copied/modified upstream core.

The current public tree is intentionally a station overlay and documentation package rather than a full fork of upstream MeteorRadio.
