# Roadmap ideas

Possible future directions, not commitments:

- clarify upstream license and publish a reproducible Adaptive Capture V2 patch
- move hard-coded reference paths into a station configuration layer
- provide a clean installation role/script for dedicated vs shared RTL-SDR modes
- add automated migration tests for score/retention state
- add example anonymized SMP dataset for renderer/classifier regression testing
- export station metrics in a standard machine-readable format
- add optional public observation summary without exposing raw station data
- document RMOB / Radio Meteor Detection Collaboration integration separately
- create a reproducible release artifact with signed checksums
